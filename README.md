# Tepkimenin Üç Yüzü

MEBİ görünümünde etkileşimli kimya laboratuvarı. Öğrenci 12 tepkimeyi gözlemler, tanecik modelini kurar ve aynı atomların izini sürer. Doğru başlangıç modeli mat CPK türleriyle 3B incelenebilir: sol tuş döndürür, sağ tuş taşır, fare tekeri yakınlaştırır. Yatay telefonda dokunma kontrolleri ve tür sayfaları vardır.

Yayın: https://hakansirints.github.io/tepkime-uc-yuz/
